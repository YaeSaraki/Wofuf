# 修复 Filter 冲突问题 - 2026-04-09

## 问题描述

在论坛模块中调用管理员接口时，仍然出现 `PermissionDeniedException: 无效的认证信息` 错误。

错误日志显示：
```
at dev.saraki.wofuf.modules.users.infra.auth.springSecurity.JwtUserAuthenticationTokenFilter.doFilterInternal
```

说明论坛模块仍在使用用户模块的 `JwtUserAuthenticationTokenFilter`，而不是我们新创建的共享 `JwtAuthenticationFilter`。

## 根本原因

论坛模块的 `build.gradle.kts` 中包含了对 `modules-users` 的依赖：
```kotlin
implementation(project(":modules-users"))
```

这导致：
1. 用户模块的 `JwtUserAuthenticationTokenFilter` 被加载
2. 该 filter 创建的是标准 `UsernamePasswordAuthenticationToken`，没有 `details` 属性
3. `PermissionAspect` 无法从 `authentication.details` 获取 `JwtTokenInfo`

## 解决方案

### 1. 添加 @Order 注解

**共享 filter (`shared-auth/JwtAuthenticationFilter`)**
```kotlin
@Component
@Order(100)
class JwtAuthenticationFilter : OncePerRequestFilter()
```

**用户模块 filter (`modules-users/JwtUserAuthenticationTokenFilter`)**
```kotlin
@Component
@Order(200)
class JwtUserAuthenticationTokenFilter: OncePerRequestFilter()
```

通过 `@Order` 注解控制 filter 执行顺序，共享 filter（100）先于用户模块 filter（200）执行。

### 2. 排除用户模块的 Filter

在论坛模块的 `ForumApplication.kt` 中使用 `@ComponentScan` 的 `excludeFilters`：

```kotlin
@ComponentScan(
    basePackages = [
        "dev.saraki.wofuf.auth",
        "dev.saraki.wofuf.shared",
        "dev.saraki.wofuf.modules.forum"
    ],
    excludeFilters = [
        // 排除用户模块的 JWT filter，避免与共享 filter 冲突
        ComponentScan.Filter(
            type = FilterType.REGEX,
            pattern = ["dev\\.saraki\\.wofuf\\.modules\\.users\\.infra\\.auth\\..*"]
        )
    ]
)
```

这样可以确保：
1. 共享的 `JwtAuthenticationFilter` 被加载
2. 用户模块的 `JwtUserAuthenticationTokenFilter` 被排除

## 架构说明

### Filter 执行顺序

```
请求 → JwtAuthenticationFilter (@Order 100)
      ├─ 验证 JWT 签名
      ├─ 提取用户信息
      └─ 设置 SecurityContext (包含 JwtTokenInfo)

      → JwtUserAuthenticationTokenFilter (@Order 200)
         └─ 在用户模块中执行（验证 Redis 会话）
         └─ 在其他模块中被排除
```

### 模块依赖关系

```
shared-auth (共享模块)
  └─ JwtValidator
  └─ JwtAuthenticationFilter

modules-users (用户模块)
  ├─ 依赖: shared-auth
  └─ 包含: JwtUserAuthenticationTokenFilter (@Order 200)

modules-forum (论坛模块)
  ├─ 依赖: shared-auth, modules-users
  └─ 排除: 用户模块的 JWT filter
```

## 注意事项

1. **不要直接依赖用户模块的 filter**：下游服务应使用 shared-auth 模块的 filter
2. **正确配置 @Order**：确保共享 filter 的优先级高于其他 filter
3. **使用 excludeFilters**：在需要排除某些 Bean 时，使用正则表达式模式
