# Document Organization

This folder contains all documentation for the Wofuf project, organized into the following structure:

## 📁 Folder Structure

### `images/`
Contains all image files used in documentation:
- PNG screenshots and diagrams
- PDF documents
- Architecture diagrams
- UI mockups

### `diagrams/`
Contains all Mermaid diagram source files:
- System architecture diagrams
- Database schemas
- API flow diagrams
- Component relationship diagrams

### `Agent/`
Contains AI agent guidelines and prompts:
- `UseCase.md` - Detailed guidelines for generating use cases
- `EventuateTramIntegration.md` - Event-driven architecture documentation

### `src/`
Contains source code examples and references used in documentation.

## 📋 File Categories

| Category | Location | File Types | Purpose |
|----------|----------|------------|---------|
| Images | `images/` | `.png`, `.pdf` | Visual documentation |
| Diagrams | `diagrams/` | `.mermaid` | Source diagrams |
| AI Guidelines | `Agent/` | `.md` | Agent prompts and rules |
| Code Examples | `src/` | Various | Reference implementations |

## 🔍 Quick Access

- **Architecture Diagrams**: `diagrams/总体架构图.mermaid`
- **Database Schema**: `diagrams/数据架构.mermaid`
- **API Documentation**: `diagrams/api.mermaid`
- **Use Case Guidelines**: `Agent/UseCase.md`
- **Event Architecture**: `Agent/EventuateTramIntegration.md`

## 📝 Contributing

When adding new documentation:
1. **Images**: Place in `images/` folder
2. **Diagrams**: Place Mermaid sources in `diagrams/`
3. **AI Guidelines**: Place in `Agent/` folder
4. **Code Examples**: Place in `src/` folder
